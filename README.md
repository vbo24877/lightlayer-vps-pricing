**同一个城市不等于同一条线路。** RackNerd在洛杉矶有两个机房，DC02走Multacom，去程电信163直连、联通169直连、移动走香港CMI，回程三网BGP，公开测评记录的国内平均延迟在200ms上下，上海电信约135ms；DC03走ColoCrossing，线路弱一些，但给的是美国原生IP并开放25端口。两家机房名字都叫洛杉矶，国内体验不在一个档次。

## 便宜机器上容易踩的五个坑

这些条款平时不写在价格表上，出问题时才知道贵。

**换IP要钱也有时限。** RackNerd购买后72小时内在控制面板可以免费换一次IP，超过72小时每次收$3。DMIT是每15天免费换一次，其他情况$5一次，2026年1月起支持自助换IP不用提工单。IP被墙是大概率事件，把这笔成本算进年度预算里更实际。

**流量超限的处理方式不同。** DMIT的Premium和Eyeball系列流量用完后直接暂停服务，机器直接不可用；Tier 1系列超量后不停机，限速到50–100Mbps继续跑。如果你跑的是长期在线的业务，停机比限速难受得多。Lightlayer的各档是固定月流量或不限流量，超限后的具体规则没有查到明确说明，买之前值得问一句。

**Windows不是每家都给。** DMIT全系只支持Linux。LisaHost支持安装Windows，HostDare的CSSD系列也支持Linux和Windows。需要远程桌面跑Windows软件的，先排除掉不支持的商家，再谈价格。

**退款窗口差别很大。** DMIT是购买3天内且流量不超过30GB可全额退，30天内按比例退剩余金额。LisaHost是48小时不满意无条件退款，窗口更短但条件更松。RackNerd和Lightlayer的退款条款在现有资料里没有明确信息。

**下架的套餐不会提前通知。** DMIT东京Eyeball系列已经从官网下架（2026年3月起），现在东京只剩Premium和Tier 1两条路。看中某个特定档位时，别拖。

## FAQ

**$25一年的机器能建站吗？**
能。1核1G加50G SSD跑一个WordPress站、日访客几百到一两千的量级没有问题。瓶颈通常在带宽和内存，不在CPU。图片多的站建议先上CDN，5M带宽直接扛图片会很吃力。

**CN2 GIA和普通线路差在哪？**
差在回程路由和晚高峰的稳定性。CN2 GIA是三网回程都走这条高端链路，普通BGP线路在晚高峰容易出现抖动和丢包。白天看不出差别，晚上八点到十一点差别明显。价格上，搬瓦工CN2 GIA-E的1G档$169.99/年，普通KVM 1G档$49.99/年，三倍多的差价买的就是这段时间。

**年付还是月付？**
年付单价低，但把钱一次性压在一家身上。第一次用某个商家，月付试一两个月更稳，尤其是退款窗口只有几天的情况下。确认线路和稳定性没问题，再转年付。DMIT洛杉矶Tier 1月付$14.90起，搬瓦工CN2 GIA-E季付$49.99，都是可以先试的口径。

**IP被墙了怎么办？**
先看商家的换IP政策。RackNerd是72小时内免费换一次、之后$3一次；DMIT是每15天免费一次、其他情况$5一次。换完还是被墙，说明这一段的IP段整体有问题，换机房比换IP更有效。

**1核1G够跑什么？**
轻量网站、代理、定时脚本、监控节点、开发测试环境。跑数据库加应用服务会紧张，2G内存起步更舒服。RackNerd的2G档$35.99/年、DMIT的TINY档给到2G内存$88.88/年，都是这个思路。

**为什么同一个价格，配置看起来差那么多？**
因为钱花在不同的地方。$24.99/年买的是机房位置和线路档位，$88.88/年买的是不超售的资源和CN2 GIA回程，$169.99/年买的是三网CN2 GIA加品牌溢价。配置表上的CPU和内存只是其中一项。
